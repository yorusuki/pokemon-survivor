# 目前護甲與防禦規則

2.2.0 起依原作物理／特殊防禦公式；先前防禦系統合計 90% 的客製上限已停用。

- 護甲本體加點上限 70%；護甲卡依原作最多 12 次。
- 本體、道具與變硬等臨時效果相加後，上限為 80%。突擊背心來源獨立保留，卸下不倒扣護甲本體。
- 使用近戰時另乘 0.75 傷害係數。
- 物理／特殊攻擊分別看目標物防 df／特防 sd；係數 clamp((75/max(5,防禦值))^0.35,0.78,1.25)，缺值依原作使用基準。
- 玩家普通傷害為 max(1,招式傷害×相剋×天氣×物特防禦係數×(1-護甲效果)×近戰係數)。純傷跳過防禦規則，最低傷害仍依既有邏輯。

例如相剋與天氣後傷害 100，護甲效果 80%、近戰且高防禦係數 0.78，實扣 11.7，合計防禦減傷約 88.3%；一般非近戰且中性防禦為實扣 20。低防禦可使傷害增加，面板出現負減傷不代表計算錯誤。相剋／天氣的額外抗性不包含在這個 88.3% 比較內。

面板與選卡分別顯示物理、特殊的最終數值。生命寶珠仍為攻擊 +30%、最大生命 -10%，與防禦分類分開；裝卸與加點不重複套生命倍率。

驗證涵蓋來源分離、裝卸順序、變硬疊層、物特係數、純傷及生命寶珠組合；不表示所有寶可夢與招式已有長局平衡驗收。
