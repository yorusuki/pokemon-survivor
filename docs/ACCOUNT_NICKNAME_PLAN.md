# 暱稱與好友代碼

狀態：已實作。公開暱稱、固定登入帳號及內部 UID 為不同資料。

## 玩家操作

- 只有已註冊並登入伺服器的帳號可以修改暱稱，包含 Google-only；訪客及純瀏覽器帳號不提供改名。
- 設定 → 帳號 → 新暱稱 → 修改暱稱。沿用 3～16 字元的 Unicode 字母／數字／底線規則；同時驗證小寫名稱鍵及實際字串長度，無法符合現有儲存規則的字元組合會拒絕。
- 成功改名後需等待完整 24 小時才能再改，不按午夜重置。畫面顯示下次可修改時間。重送相同名稱不消耗冷卻，僅修改大小寫仍算改名。首次設定暱稱不消耗冷卻。
- 舊名保留 7 天，期間只有原帳號可在冷卻結束後取回；到期後其他人可使用。重新使用保留名時移除該保留。搜尋不以舊名自動導向新名。
- 必須離開合作房間並回到主選單改名；暫停中的遊戲仍不允許。伺服器另檢查合作房間成員與租約，避免從其他分頁繞過房內限制。
- 登入帳號不變，設定頁會顯示原密碼登入帳號；Google-only 不顯示合成的登入識別碼。UID、密碼、Google 綁定、好友與進度不因改名更換。

## 好友代碼

好友畫面顯示專用 `PS-` 代碼與複製按鈕。複製後分享給朋友，對方在新增好友欄位貼上代碼即可送出申請；不再要求手打暱稱。支援貼上前後空白及英文小寫的正規化。

代碼由伺服器密碼學安全亂數產生，具有 80 bits 隨機性，不由 UID、註冊順序或暱稱推算。每帳號固定一組，改名不變；舊帳號於啟用新版本後首次使用帳號功能時建立。代碼不是登入憑證或權限密碼；內部 UID 仍會用於房間與好友 API，不宣稱它是保密資料。

只在已登入的帳號 API 查自己的代碼；好友查詢需要完整代碼，每帳號每分鐘最多 20 次。查詢回應僅提供後續好友流程需要的 UID 與目前暱稱，不回傳對方代碼。剪貼簿不可用時會選取代碼，供手動複製。

好友關係仍以 UID 綁定。好友清單批次投影最新名稱，不在改名時重寫所有好友；公開 profile 名稱變動會清除相關顯示快取。邀請更新為目前名稱，歷史排行榜保留當時的名稱快照。

## 資料與部署

新增 `account_settings`（帳號代碼、上次改名時間）與 `nickname_holds`（舊名保留至期），具備唯一性、外鍵與到期索引。資料表不開放一般 documents API；刪除帳號時由外鍵一併清理。

升級前另行備份 PostgreSQL 與部署用環境設定。保留 Compose 專案名稱及既有 volume，再執行：

```sh
docker compose config --quiet
docker compose up -d --build --force-recreate db-init api pokesurvivor-web
docker compose ps
docker compose logs --tail=80 db-init api
```

`db-init` 先建立新增表及 runtime 權限，成功後 API 才啟動；不重設使用者、存檔或好友。Schema 可重跑，代碼延後建立，無須對每位舊玩家預先配碼。發布時應更新全部前端並要求舊分頁重新載入，避免舊版仍顯示暱稱搜尋。

一般文件 API 不允許改公開名稱或刪除現行名稱繞過冷卻；存檔寫入會使用伺服器目前暱稱，避免舊裝置覆蓋。名稱保留、公開 profile、使用者顯示名、邀請及存檔更新在同一交易完成，錯誤整筆回滾。

## 驗證與限制

測試涵蓋登入／CSRF、代碼穩定與唯一性、查詢限流、24 小時與 7 天邊界、重名競爭、房間限制、舊同步、交易中途失敗回滾、Google-only、schema 重跑、runtime 權限及刪帳號清理。

客戶端畫面顯示的解鎖時間受裝置時鐘影響，伺服器判定才是準據。正式容器升級、不同瀏覽器剪貼簿權限及跨網路多人遊玩仍須部署驗收。程式回滾不等於資料回滾，不應為了降版刪除已配出的好友代碼。
