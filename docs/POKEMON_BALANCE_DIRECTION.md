# 原作參考與後續補強方向（尚未實作）

> 目前決策請以 [平衡綜合方案](BALANCE_PLAN.md) 為準；本文件保留研究與歷史提案，未核准的數值並未套用。


原作有 HP、攻擊、防禦、特攻、特防、速度六項能力。官方概述：https://www.pokemon.com/us/features/pokemon-rpgs-101 。官方對戰說明：https://diamondpearl.pokemon.com/en-us/trainersguide/fundamentals/battling/ 。

## 本專案實際改編

- tools/fetch_pokedex.py：hp=round(70+原作HP×0.45)，spd=round(78+原作速度×0.42)，atk=round(0.70+max(物攻,特攻)/100×0.55,2)。不是主系列遊戲的等級／個體值／努力值能力公式。
- 原作速度在主系列主要影響行動順序，本作換成即時移動速度。原作防禦與特防沒有換成玩家對應的基礎減傷；不能說完整保留了原作種族特色。
- js/data/types.js 的 CHART 參考原作相剋關係，但運行時將 2／0.5／0 改成 1.6／0.6／0.3，雙屬性限制 0.3～2.4；目前不是原作主系列倍率，也不能把 1.6 精確視為 Pokemon GO 的完整規則。
- 未看到主系列 STAB 同屬性招式增傷；星級由本專案依種族值總和與傳說等標記決定。玩家永久強化、能力卡與一般治療者倍率是本作系統。

## 建議方向

本次停止先前壓平玩家面板、修改屬性倍率的提案，沒有套用。保留原作來源資料與現有相剋，先研究獨立的實際戰鬥換算／補強層：

1. 補回被省略的耐久特色：從可追溯資料取得防禦與特防，再設計有上限的耐久換算；不直接加在既有 80% 減傷上限之外，避免近乎無敵。
2. 補強依實際戰力與角色缺口，不依星級統一加點；高雙防、低速度的角色不應在轉成即時遊戲後只剩缺點。
3. 培育補強與每個帳號／每隻寶可夢隔離，合理投入即可使用，不增加一套漫長刷取作為弱勢的代價。
4. 種族被動與可取得的補盲招式可以保留特色，但其數值與學習條件需先提案，不宣稱屬於原作原封不動的機制。
5. 先比較零／中／滿永久強化下的清群、頭目、生存及經驗效率，再決定補正；資料補齊、存檔版本與伺服器驗證需另行設計並取得同意。

例如壺壺目前是 HP79、速度80、攻擊0.76、4星；僅按星級給點無法充分解釋或補回它依賴的防禦定位。這說明需要查明哪些原作優勢在轉換中被省略，而不是先把所有喜愛角色調成同一組數字。
