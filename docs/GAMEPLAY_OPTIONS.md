# 合作選卡、紀念名稱與畫面設定

## 合作模式升級

維持全隊暫停、所有在線成員選完才恢復的玩法，不強迫玩家倒數自動選卡。暫停時房主戰場快照由約每秒 15 次降為每秒 5 次，並省略停止中的敵人清單；選完、等待名單變更及恢復通知立即發送，不等下一次週期。玩家間心跳／狀態仍持續。

選擇確認 lp 與恢復 lr 附帶升級回合號；上一輪延遲訊息不能誤解除新一輪等待。完整狀態的已選回合 doneSeq 仍保留作為補償。等待名單不變時不重寫 DOM，避免額外翻譯與畫面更新。

部署後所有玩家須重新整理並重建房間，新舊協定混用可能被安全驗證拒絕。本次沒有更改 TURN 期限、配額，也不代表所有網路的延遲已消除；對方仍未選卡時繼續等待屬正常。

## 30 分鐘紀念名稱

每個帳號、每個寶可夢 dex 分開記錄 save.survivalBest[dex]（整數秒），一般與異色共用。達到 1800 秒時記錄並提交，結算時更新最佳值；主選單夥伴名稱、收藏卡片、詳細資料及遊戲 HUD 顯示金字與閃光（已移除外框），不再追加 ✦30′ 徽章。只改名稱呈現，不更改儲存的名字、不影響暱稱／登入，也不提供戰鬥加成。

舊存檔缺欄位時自動補空物件，多裝置以各 dex 最大值合併，不會被較短紀錄覆蓋。伺服器限制 ID、整數範圍、項目數與存檔大小。訪客紀念名稱只在該次瀏覽器記憶體中，不會永久保存。

先前帳號總最佳時間不能反推出使用哪隻寶可夢，因此不一律補發舊紀錄。紀念名稱仍依玩家端冒險時間計算，不是新的伺服器反作弊認證。合作模式以該玩家參與的冒險時間計算，含可被救起的倒地期間。

## 設定 → 畫面

- 己方攻擊特效不透明度：0～100%，每格 5%，預設 100%。涵蓋己方及隊友投射物、軌道、持續範圍、施放／命中粒子與光束等；不改傷害與碰撞。敵方投射物、攻擊預警、角色與傷害數字不隨此設定隱藏。
- 血條位置：畫面左上方（預設）或角色下方。角色下方採固定螢幕尺寸，避免手機縮放造成文字過小。
- 顯示血量數字：預設開啟，可關閉；與位置設定獨立。

以上設定存在目前裝置的 ps.settings，不寫資料庫，不跨裝置同步。暫停選單可打開設定立即調整；合作模式暫停選單不代表整隊暫停，調整時仍須注意敵人。

## 部署與資料影響

本次不新增或修改 PostgreSQL table／column，僅沿用 saves JSON 增加 survivalBest；舊帳號不需執行 SQL。保留正式 .env 與資料庫 volume，更新程式後執行 docker compose up -d --build，所有玩家重新整理。


技能點補強目前只有 [待確認方案](POKEMON_TALENTS_PROPOSAL.md)，不包含在此次遊戲更新中。

## 驗收

自動化涵蓋舊存檔／單隻徽章／max 合併、設定邊界、敵我透明度隔離、升級暫停同步與舊回合確認、伺服器生存紀錄驗證。隔離資料庫與預覽測試不等同正式部署驗收。

仍需 實際容器 與不同網路四人實測升級、連續升級、道具／連結選擇交錯及斷線。沒有用單機預覽代替跨網路效能驗證。

## 招式儲備開關與道具詢問（2026-10-18）

永久強化的「招式儲備」購買後，該項下方獨立一行顯示開啟／關閉按鈕，購買後不再顯示單格進度點或「已達上限」按鈕。以每個帳號、每隻寶可夢獨立保存，關閉只停用下一場的額外隨機初始攻擊招式，不退費、不移除購買等級、不移除基本初始招式。舊存檔沒有偏好時維持開啟，未購買者不能藉開關取得效果。

偏好保存於 saves JSON 的 moveReserve[dex] = {enabled, at}，較新時間優先，相同時間以停用優先；裝置時鐘差異會影響衝突先後。伺服器驗證 ID、布林與時間戳，無 SQL migration。開新局讀取，當局不受選單開關影響。

初次拾取道具會顯示「不裝備／裝備」，已有道具則維持「保留／更換」。拒絕不觸發裝備效果；拾取物已消耗，不會留在地上。選擇時暫停，合作沿用全隊等待機制；與升級選卡、連續取得多件道具會依序處理。與以往相同，道具僅維持該場遊戲、同時只能裝備一件。

金色名稱沿用原達到 1800 秒的紀錄，不新增擊敗阿爾宙斯條件，也不重新判定舊紀錄。主選單、收藏格、詳情及遊戲左上名稱都套用。閃光不代表變為異色，也沒有能力加成；系統減少動態效果偏好會停止 DOM 閃光動畫，遊戲減少閃動設定會將 HUD 閃光固定。

## 紀念金字／閃光未顯示的排查

先看寶可夢選擇／收藏格及右側詳情的名稱，再看主選單與 HUD。效果只裝飾寶可夢名稱，不代表圖像外框、玩家暱稱或排行榜都有同一效果。

- 必須同帳號、同 dex 的 survivalBest 至少 1800 秒；不是角色等級 30，也不是所有寶可夢共用總最佳時間。
- 功能加入前只有帳號總紀錄的舊成績，不能推定屬於哪隻，因此沒有自動補發；換寶可夢或換帳號也不會沿用。
- 訪客不持久保存；帳號若未成功同步，其他裝置可能尚未取得紀錄。一般與異色共用同 dex。
- 新版 CSS 使用內容雜湊網址，與更新器版本一起變動，減少 JS 已更新但樣式仍舊的情況。仍須確認部署有重新建置，Cloudflare 自訂快取沒有忽略 query 或強制快取舊 HTML。
- 系統減少動態效果會停止 CSS 閃光動畫，遊戲的減少閃動會讓 HUD 閃光固定；金字仍應存在，不應把完全沒有金字歸因於此設定。

收藏名稱保留閃光與金字，已移除名稱外框、框線光暈與底色；長名稱仍以省略號控制寬度。排查時需確認玩家的逐隻紀錄，仍需比對其部署版本及逐隻紀錄。

## 更新內容與快取、個人狀態

通常不需要管理者替所有玩家清快取。建置時 JS 與 CSS 有版本網址；更新器首次載入約 30 秒檢查，之後每 5 分鐘檢查，切回分頁且距上次檢查超過一分鐘也會檢查。偵測新版後，安全狀態倒數 5 秒再載入；對局、結算、抽卡、強化、設定及輸入中會暫緩，回主選單才更新。

長時間沒關閉的分頁仍在執行記憶體中的舊程式，不是每次操作都從伺服器重新下載。Service Worker 對程式採網路優先，斷網時可回用舊快取；圖片與字型則優先用素材快取。若部署未重建，或 Cloudflare 自訂規則快取舊 HTML／忽略 query，玩家可能仍收到舊入口。正式站快取規則須另行檢查。

字型、音量、畫面偏好等保存在 localStorage，逐隻紀錄另隨帳號存檔同步，與下載的 JS／CSS 快取不同。更新不會強制覆蓋已保存的平滑字型設定，也不會替沒有逐隻 30 分鐘紀錄的角色補發效果。

排查順序：先結束當局並回主選單，再重新整理或關閉分頁重開；仍是舊版時才做強制重新整理，部署端再比對 version.json 與入口版本。一般不需要清除整個站台資料；那會連登入、偏好及尚未同步的本機資料一起清掉。管理者清 CDN 快取與玩家瀏覽器／PWA 快取不是同一件事。

字重維持原設定：收藏格 b 與詳情標題通常為 700、主選單名稱 700、HUD 800；紀念名稱本身沒有額外提高字重。實際像素字型的粗細觀感亦受字型與瀏覽器繪製影響。


## 2.1.0：暫停統計與輸入

- 暫停畫面會顯示每個已學招式的直接傷害與平均每秒傷害、目前能力、道具與已選強化。DPS 依學會後的遊戲時間平均（至少 5 秒），包含未使用該招的時間，單人暫停不增加分母；多人選單若場次仍進行則時間照走。包含溢出傷害，不含中毒／灼傷跳傷及地圖物件，不代表精準擊殺貢獻。
- 設定 → 操作可開關手把與震動；標準配置為左搖桿／方向鍵移動與導航，LB／RB 或 LT／RT 切招，Start 暫停，A 確認，B 返回，Y 重抽，右搖桿捲動清單。文字輸入仍使用鍵盤或系統輸入法。
- 設定 → 輔助功能可開啟手動瞄準，預設關閉。滑鼠／右搖桿決定攻擊方向；近戰、光束、投射物、迴力鏢、衝刺及錐形攻擊可朝空處施放；連鎖及隕石仍需目標。放開右搖桿且未移動滑鼠時回到自動瞄準。
- 選卡、連結及道具視窗出現後 0.6 秒為防誤觸期；重抽後與連結第二步會重新開始保護期。無論鍵盤、滑鼠、觸控或手把都適用，不會替玩家自動選擇。
- 大型角色視覺縮放採原作新規則，碰撞半徑上限 18；本機與遠端角色一致。血條位置、金字與攻擊透明度設定保留。
- iPhone 尺寸改動會重測 Canvas 與安全區；設定頁籤可橫向捲動。實際主畫面模式及手把相容性仍依裝置與瀏覽器，需要實體驗收。

Gamepad API 可能被瀏覽器的權限政策限制，無法使用時保留鍵盤與觸控；震動失敗也不應中斷遊戲。參考 [Gamepad API](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/getGamepads)、[震動 API](https://developer.mozilla.org/en-US/docs/Web/API/GamepadHapticActuator/playEffect)、[ResizeObserver](https://developer.mozilla.org/en-US/docs/Web/API/ResizeObserver)。
