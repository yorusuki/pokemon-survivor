# 版本回滾與資料保護

Git 保存程式碼，不保存 `.env`、帳號存檔或 PostgreSQL 資料。升級與回滾前，分別保護部署設定及資料庫備份，見 [部署文件](SELF_HOSTING.md)。

## 程式版本

以 `git log --oneline` 查詢提交。單一變更可評估 `git revert <commit>`；檢查整個舊版本時使用獨立目錄或 worktree，避免覆蓋部署設定，並重新驗證與建置。

沿用既有 Compose 專案名稱及資料卷。不要執行 `docker compose down -v`，也不要只修改環境變數便假設資料庫密碼已輪換。

## 資料相容性

程式回滾不等於資料回滾。Google-only 帳號需要支援 Google 身分表及可空密碼的版本；舊版可能無法登入。還原資料庫備份會失去備份後的資料，須先另存現況並確認影響。

一次性配發已有玩家消費後，不可只刪除配發標記當作回滾。舊版亦可能帶回已修復漏洞，應僅供受控排錯。

## 封存還原工具

`tools/restore_backup.py` 可驗證符合其 manifest 格式的封存並解壓到新目錄。私人封存、manifest 與實際備份路徑不應放入公開文件。還原程式碼封存不會還原資料庫。
