# 低星寶可夢補強方案（待確認，尚未實作）

> 目前決策請以 [平衡綜合方案](BALANCE_PLAN.md) 為準；本文件保留研究與歷史提案，未核准的數值並未套用。


## 建議數值

每個帳號、每隻已擁有的寶可夢獨立分配，星級 1／2／3／4／5 星分別有 4／3／2／1／0 點。每點提高所選能力 2%，最多 4 點，即單項最多 8%。可選最大血量、攻擊、移動速度、減傷；減傷採乘法套用剩餘傷害，不能堆到免疫。不加成冷卻、經驗或金幣，避免破壞既有經濟。

此數值是第一版提案，低星的基礎種族值差距未必能靠 8% 補足；需以同等永久強化、相同招式及遊戲時間比較後再調整，不能先宣稱已平衡。

僅在主選單分配，可免費重置；一般與異色共用，同帳號不同寶可夢不共用。點數由當前稀有度推導，不透過一次性發獎，避免重複領取。原有付費強化 pupg 保留，額外點數另外保存。

## 資料與流程

建議使用既有 saves.data 的 save.talents[dex]，記錄 hp／atk／spd／def 配點與版本；不新增 PostgreSQL table／column。舊存檔缺欄位視為零配點，不自動花點。伺服器檢查擁有資格、稀有度對應預算、各項整數與總和，拒絕未知能力。

配點採伺服器 revision 交易：讀取 → 驗證 → 提交 → 衝突時要求重載。不能沿用永久升級各項取 max 的合併方式，否則重置或多裝置不同配點可能合併成超額。需為此欄位設計明確的版本合併與重置流程。

## 範圍與風險

中等規模：永久強化畫面、新配點 API、存檔遷移與合併、玩家基礎能力計算、合作模式能力傳輸與回歸測試；不需要大量改表或停機搬移。仍沿用玩家端遊戲模擬，不等同反作弊系統。

驗證需涵蓋多帳號隔離、多寶可夢隔離、配點／重置、越界拒絕、同時更新、離線快取衝突、單人及四人能力一致性。此項目仍為提案，此功能與首頁宣傳均尚未啟用。
