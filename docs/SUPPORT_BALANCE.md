# 敵方治療與護盾平衡（2026-10-18 第四版）

原始模式封存於 [SUPPORT_ORIGINAL.md](SUPPORT_ORIGINAL.md)。第一版「4%、5 人、共用 30% 回復預算」已由本版取代；本版護盾亦採等級比例與共同間隔。

## 本版治療規則

| 項目 | 目前設定 |
|---|---|
| 每次回血 | 目標最大生命 5%～12%，不超過缺少血量 |
| 等級換算 | 玩家 Lv.1 為 5%、Lv.100 為 12%，中間線性增加，100 以上封頂；比例 = .05 + .07 × (clamp(L,1,100)-1)/99 |
| 合作等級 | 存活玩家最高等級；沒有有效等級時以 Lv.1 計算。不看玩家攻擊加成 |
| 每位治療者施法冷卻 | 保留原始 5 秒與原來的施法觸發條件 |
| 同目標受療間隔 | 依上次成功受療時的冒險時間：2 + 6 × clamp(秒數 / 1800, 0, 1) 秒；同一場所有治療者共用，30 分鐘後封頂 8 秒 |
| 目標數 | 範圍內全部受傷存活目標，沒有 5 人限制 |
| 自療／互補 | 不能補自己，可以被其他治療者補 |
| 特殊敵人 | 恢復原來可接受治療的頭目、傳說、制裁個體；阿爾宙斯本體不是一般 Enemy 生命物件，不因此變成可治療目標 |
| 距離／牆壁 | 回到原 queryCircle(150)，包含目標碰撞半徑；可以穿牆 |
| 生成保護期 | 前 60 秒不生成一般治療者／護盾者；60 秒起仍須符合敵人池條件 |
| 場上上限 | 一般生成器的治療者單人／合作均最多 25 隻；達限改從其他候選敵人生成 |
| 累積回血預算 | 移除，不再限制回血總量 |

死亡或遠端訪客副本不能自行回復；合作仍由房主計算後同步，不能為恢復舊規則而恢復重複模擬。

## 累積回復限制原本的意思

第一版會記錄每個敵人實際承受的生命／護盾傷害 D，以及已回血／補盾總量 R，要求 R ≤ 0.3D。例如實際承受 1000 傷害，只允許累積補回 300。這不是每次補 30%，也不是只允許回到 30% 血量；溢出傷害不計，換治療來源不重置。

現在回血與補盾都不再有累積傷害預算。原始模式與前兩版可由 Git 與原始封存文件查閱；不能把歷史 30% 預算誤認成目前規則。

## 護盾者第四版

- 依存活玩家最高等級，Lv.1 為最大生命 10%、Lv.100 為 40%，線性增加並封頂：.1 + .3 × (clamp(L,1,100)-1)/99。
- 同一目標 2.5 秒內最多接受一次實際新增護盾，跨不同來源共用。護盾最多補至該等級比例，不能由 25 名施法者堆成數倍生命；滿盾不新增、不刷新持續時間或消耗間隔。若存活最高等級降低，既有較高護盾不會被較低比例施法削減，只是不再追加，仍受原持續時間限制。
- 不替自己上盾，可接受其他護盾者支援；可穿牆、可替頭目／傳說／制裁敵人上盾。阿爾宙斯本體不是這類 Enemy 目標。
- 保留 160 中心距離、每次最多 6 目標、護盾持續 8 秒，以及每名護盾者原有 6 秒施法冷卻。2.5 秒是目標共用間隔，沒有把個別施法冷卻改成 2.5 秒。
- 一般生成器治療者與護盾者各最多 25 隻，合計最多 50，但仍受一般敵人總數 64 限制；前 60 秒皆不生成。

## 修改前平衡評估與取捨

這不是保證所有輸出都能擊殺的版本。多個治療者錯開施法時，受療間隔由 2 秒增至 8 秒。開局理論每秒回復最大生命 2.5～6%，15 分鐘時 1～2.4%，30 分鐘後 0.625～1.5%；實際比例仍取決於玩家等級，單一治療者保留 5 秒冷卻，實際頻率可能更低。與第一版每 5 秒 4%、最多 5 人且有限額相比，屬明顯上調。

主要風險為：低輸出追不上回血、25 隻治療者互補形成團塊、隔牆支援不容易優先擊殺，以及高血量頭目／後期傳說的百分比回血超過玩家輸出。不限人數也增加群體粒子數與房主工作量。加上最高 40% 護盾與 2.5 秒跨來源補盾，特殊敵人更可能需要爆發輸出或優先處理支援；64 隻上限中最多 50 隻可為支援，群體組成會明顯改變。傷害、命中、群聚與施法時序會影響結果，不應把上面的理論每秒速率視為固定施法。

此次照指定規則實作，不私自保留回血總額上限。若實戰再次拖住，建議依序調整特殊敵人的受療倍率、治療者互補、治療者數量，再考慮所有敵人的回血比例；這些只是後續建議，未套用。

## 驗證與部署

自動化載入實際 Enemy／Spawner，涵蓋等級換算、多人最高存活等級、2～8 秒跨來源限制與 30 分鐘封頂、自療排除與互補、全範圍／特殊目標／穿牆、死亡及遠端排除、護盾等級與 2.5 秒間隔、60 秒與各 25 隻生成界線。另保留低輸出可能無法擊殺的測試，明確反映本版風險，不將它誤報為全輸出可通關。

無資料庫或私密 ENV 變更。部署機執行 docker compose up -d --build；玩家重新整理並開新局，合作請全員更新。實際容器、四人跨網路及長局難度仍需部署端驗收。

## 時間間隔與實際頻率

| 遊玩時間 | 同目標受療間隔 | 相對原 3 秒規則的最大頻率 |
|---|---|---|
| 1 分鐘（一般支援開始生成） | 2.2 秒 | +36.4% |
| 5 分鐘 | 3 秒 | 相同 |
| 15 分鐘 | 5 秒 | -40% |
| 30 分鐘及之後 | 8 秒 | -62.5% |

以成功受療當下的時間鎖定這次間隔，避免等待門檻持續移動；暫停不計時，滿血或失敗治療不消耗間隔。高等級也不能縮短間隔；升級只改變單次回復比例。護盾仍為獨立的 2.5 秒規則。前 5 分鐘比原規則略強，後期降低連續補血阻擋擊殺的風險，但不能保證任意低輸出都能擊殺。
