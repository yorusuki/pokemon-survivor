# 目前支援敵人規則

2.2.0 起依原作者固定提交 e4ba0e1；[初始模式封存](SUPPORT_ORIGINAL.md)保留作歷史依據，不是目前切換開關。

| 規則 | 目前結果 |
|---|---|
| 治療比例 | 7% × min(2.5,最高玩家攻擊倍率^0.35)，約 7～17.5% 最大生命 |
| 治療施法 | 每個治療者原作 3.5 秒施法冷卻；不限同次治療人數，可自療、互補、隔牆及作用於特殊敵人 |
| 治療目標間隔 | 不再使用本分支先前 2→8 秒共用間隔 |
| 普通護盾 | 最近最多 6 個存活目標補至 35% 最大生命，持續 8 秒，可包括施法者；沒有一般目標的 2.5 秒共同間隔 |
| 頭目治療 | 每次不超過近期估計 DPS×0.4 |
| 頭目護盾 | 不超過 min(35% 最大生命,近期估計 DPS×1.2)，shieldT≤2 才能再施放，對應原 8 秒時效中的約 6 秒間隔 |
| 近期 DPS | 頭目命中傷害 rd，包含護盾吸收量；以 6 秒時間常數指數衰減，DPS=rd/6，不是固定視窗平均 |
| 距離 | 治療 queryCircle 150、護盾 160，依原空間查詢包含目標半徑；不做牆壁遮擋 |
| 數量 | 一般生成器對治療者／護盾者／召喚者各限制 3 個存活個體，仍受總敵人與事件規則影響 |
| 開場 | 移除客製前 60 秒禁止支援；仍依原作敵人池時間條件出現，不代表第 0 秒必出 |

已移除「依玩家等級 5～12% 治療、10～40% 護盾、不自補、各 25 隻」客製規則。頭目上限只套於 boss 標記個體，不等於所有稀有或特殊名稱個體；原作註解的輸出／回復估計不保證所有地形、走位與組合都能擊殺。

2.3.1 校正敵人定義產生器遺留的5秒設定，完整對齊已採用原作803125d；先前文件稱5秒為原作是錯誤記載。連續處於施法條件下，相較5秒約提高42.9%施法頻率，但實際仍受距離、暈眩與目標狀態影響。
