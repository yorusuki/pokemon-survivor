# 每場招式池與強化限制

2.2.0：65 個基礎招式（新增詭計），可學池由寶可夢自身屬性＋一般池組成；不在開局鎖死整場招式。原作能學不代表本作全部開放。

每次升級先按權重不重複取最多6個新招候選，強項／無物特分類權重2、弱項1，再與既有招式強化及能力卡混合抽選。最終卡片不是固定雙倍機率，也不保證抽齊。滿4欄不提供新招、被禁止招式排除、最多2個buff、招式一般強化到Lv.5；連結仍最多13個基礎招式，進化不另佔欄位。

詭計在一般池供所有寶可夢學習；劍舞／龍之舞只加物攻，詭計只加特攻。每次升級重抽候選，不是看不到一次就永遠不能取得。永久招式儲備開關保留，關閉時不提供第二起始招式。護甲卡跟原作依次數限制，不再用先前本體達70%就隱藏的客製篩選。
