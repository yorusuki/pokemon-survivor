# 最愛、字型與能力顯示

## 操作

- 收藏／寶可夢選擇畫面最左側有獨立「最愛」篩選，下方另列「0/100」，字級與地區選項相同，與世代按鈕略為隔開。快速點同一隻兩次（350ms 內）加入／取消，顯示提示，收藏格上方保留愛心。詳情保留置中雙擊提示，沒有另增最愛按鈕。最愛篩選跨世代；可標記尚未擁有的寶可夢，但不會解鎖或揭露其內容。
- 此 100 隻私人收藏與個人檔案原有的 3 隻公開展示分開。登入帳號會隨存檔同步；訪客不保證持久保存。
- 設定 → 畫面 → 介面字型：未有字型偏好時預設 Cubic 11 像素字型，可切換平滑字型，保留已有明確偏好。套用於 DOM 與 Canvas 的繪字／測量，保留系統缺字後備。字型隨網站供應，不向外部字型服務請求；來源、OFL 見 CREDITS.md。
- 角色下方血條再向下移 12 個畫面像素。極端大型攻擊效果仍可能掃過血條，可切回原 HUD。
- 設定 → 畫面 → 加成面板：左下、右下（預設）、不顯示。背景約 33% 不透明且不攔截操作，只列有效加成、已攜帶道具與生效祭壇；零加成、空道具及預設重抽不列，全部沒有時隱藏。
- 面板顯示目前結果，不列基礎值與乘算拆解。一般冷卻以原冷卻所需時間的百分比顯示（80% 表示所需時間為原來八成）；經驗／金額以實際取得比例顯示。攻擊數字沿用本作角色攻擊能力，實際每招傷害仍依招式及相剋等規則決定，不虛構一個所有招式通用的傷害值。
- 升級能力卡以「攻擊：1.06 → 1.17」等簡短結果取代倍率說明；沿用實際卡片規則在副本上預估，不寫入角色。招式升級保留效果說明與簡短等級變化。累計摘要預設收合，點開才顯示，展開內容限制高度並可捲動。

## 資料與限制

既有 saves JSON 新增可選 favorites：圖鑑編號 → {on, at}。舊存檔自動補空集合，無 SQL migration。伺服器驗證圖鑑 1～1025、格式、時間戳與最多 100 筆啟用；取消保留時間戳，避免舊裝置復活。衝突取較新時間，相同時間以取消優先；超額按時間與編號固定裁切。裝置時鐘差異仍會影響先後判定。

字型、面板位置與血條設定僅存在該瀏覽器，不同步至帳號。面板每 250ms 至多更新一次；個人經驗加成不代表合作共享計算後的團隊最終倍率。相剋、天氣傷害、軌道命中間隔及純粹傷害仍依各自規則，沒有改動戰鬥平衡。

## 部署與驗證

在部署機保留既有 .env，執行 docker compose up -d --build，玩家重新整理。前端與 API 應一起更新；舊 API 不認得新增收藏欄位時可能拒絕存檔。無新依賴、無新資料表。Cubic 字型檔約 391 KiB，首次載入速度依連線而異。

自動化涵蓋收藏上限、取消合併、伺服器拒絕異常格式、字型繪字及測量、有效加成篩選與卡片預估。實際裝置、觸控雙擊和四人長局仍需部署端驗收。

## 收藏提示

詳情區不再放置額外的加入／取消最愛按鈕，改為置中、可換行的雙擊提示。快速點選列表中的同一隻寶可夢兩下，可加入或取消最愛；常態愛心與 0／100 計數保留。最愛篩選與其他世代選項使用相同字級與版面，間距隨可用寬度縮放。
